# Classic Snake Game in C 🐍

A simple, console-based Snake game written entirely in C. This project demonstrates core programming concepts like game loops, array manipulation, and real-time keyboard input.

## Features
* Classic grid-based movement
* Dynamic tail growth upon eating fruit
* Score tracking
* Border and self-collision detection

## Prerequisites
* A C compiler (like GCC via MinGW)
* **OS:** Windows (This game uses `<windows.h>` and `<conio.h>` for console manipulation and real-time input)

## How to Run
1. Clone this repository or download the `snake.c` file.
2. Open your terminal or command prompt in the folder containing the file.
3. Compile the code using GCC:
   gcc snake.c -o snake
